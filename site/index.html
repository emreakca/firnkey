Everything you need, nothing you don't.

One Manifest V3 extension that keeps the browser side light. Permissions are asked for only when a feature needs them.

Fills where you type

Suggestions in the login field, a keyboard shortcut, or the right-click menu. Cards, identities and one-time codes too.

Passkeys

Create passkeys on websites and sign in with them, stored in your own vault.

Strong sign-in

PBKDF2 and Argon2id. Authenticator app, email, YubiKey, security keys, Duo, SSO and login with device.

Unlock in a touch

Touch ID, Windows Hello or a PIN. Lock on a timer, when the computer locks, or when the browser closes.

Generator with memory

Passwords, passphrases, usernames and email aliases. Every password you used is remembered, encrypted, with its website.

Password health

Finds weak and reused passwords and, if you turn it on, ones that appeared in known data breaches.

Live sync

Changes arrive instantly through your server's notification hub. Several accounts and organizations, one click apart.

Send and SSH keys

Share text or files through self-deleting encrypted links. Generate Ed25519 keys and fill their public half.

Move in, move out

Import from Bitwarden, 1Password, KeePass and browser CSV exports. Export to Bitwarden JSON any time.

Encrypted on your device. Stored on your server.

Only your server

Firnkey connects to the one address you enter. Plain HTTP is allowed only for localhost.

Master password never stored

It derives your keys, then it is dropped. Decrypted items live only in the extension's memory.

Websites stay closed

No access to any page until you turn on website integration. Logins for a subdomain are never offered on its parent.

No telemetry

No tracking, no analytics, no remote code. The optional breach check sends only 5 characters of a hash.

Get started

  1. Install Firnkey from the Chrome Web Store (also works in Edge, Brave and other Chromium browsers) or from Firefox Add-ons (Firefox 140+).
  2. Enter your server address and sign in. Firnkey asks for access to that one server only.

Prefer to build it yourself? Every release is on GitHub, and pnpm verify builds it from source.

Questions

What is Firnkey?

Firnkey is a free, open-source password manager extension for Chrome and Firefox. It stores nothing with us: it connects only to a password server you host yourself.

Does Firnkey work with Vaultwarden?

Yes. Firnkey works with Vaultwarden and any other self-hosted server that speaks the Bitwarden API. You enter its address once; Firnkey talks to no other server.

Can I use Firnkey instead of the Bitwarden browser extension?

Yes, for a self-hosted server. Firnkey uses the same vault, so Bitwarden's mobile and desktop apps keep working alongside it. It is a lighter browser extension with a smaller footprint and permissions asked for only when a feature needs them.

Which browsers are supported?

Chrome, Edge, Brave and other Chromium browsers through the Chrome Web Store, and Firefox 140 or newer through Firefox Add-ons.

Is Firnkey free?

Yes. It is non-commercial and licensed under GPL-3.0, with no paid tier, ads or account with us.

Does Firnkey support passkeys and one-time codes?

Yes. It creates and uses passkeys, fills TOTP codes, cards and identities, and supports two-step login with authenticator apps, email, YubiKey, security keys, Duo and SSO.

Does Firnkey collect any data?

No. There is no telemetry, no analytics and no remote code. Your vault is encrypted on your device and stored on your server.

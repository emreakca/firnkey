# Firnkey v1.0.0

First release of Firnkey, a lightweight Manifest V3 browser client for Vaultwarden and compatible
Bitwarden API servers. See the [README](../../README.md) for the full feature list and security model.

Firnkey is based on [LeanVault](https://github.com/jsjain/vaultwarden-chrome-extension) 1.0.2 by
Shubham Jain and extends it with two-step login (including security keys and Duo), encryption v2
accounts, live sync, passkeys, HTTP basic-auth filling, biometric unlock, localization, and more.

## Installation

```sh
git clone https://github.com/emreakca/firnkey.git
cd firnkey
git checkout v1.0.0
pnpm install
pnpm verify
```

Then load the generated `dist/` folder at `chrome://extensions` with **Developer mode** on, and
confirm **1.0.0** in Firnkey **Settings**.

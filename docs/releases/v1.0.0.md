# Firnkey v1.0.0

First release of Firnkey, a lightweight Manifest V3 browser client for self-hosted password
servers. See the [README](../../README.md) for the full feature list and security model.

Highlights: two-step login (including security keys and Duo), encryption v2 accounts, live sync,
passkeys, HTTP basic-auth filling, biometric unlock, English and German, and an encrypted generator
history that records the website each password was made for. Sites with several accounts keep the
chosen one first and fill its password on the next sign-in step; cards and addresses fill whole
forms and are offered for saving; SSH keys can be generated and edited. The look follows the
edelweiss icon: alpine blue, snow white and a golden center.

## Installation

```sh
git clone https://github.com/emreakca/firnkey.git
cd firnkey
git checkout v1.0.0
pnpm install
pnpm verify
```

Then load the generated `dist/` folder at `chrome://extensions` with **Developer mode** on, and
confirm **1.0.0** in Firnkey **Settings**.
